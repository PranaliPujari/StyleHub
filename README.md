# 👗 StyleHub – Modern Fashion Shopping Website

StyleHub is a modern and responsive fashion e-commerce website UI/UX design created using Figma as part of my CodeNova UI/UX Design Internship (Task 2).

## ✨ Project Features
- Modern fashion homepage
- Desktop and mobile responsive designs
- Women's and men's fashion categories
- New arrivals and best sellers
- Product details page
- Shopping cart page
- Reusable UI components
- Complete design system

## 🛠️ Tools Used
- Figma
- UI/UX Design
- Auto Layout
- Components and Variants
